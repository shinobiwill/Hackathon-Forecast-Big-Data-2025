# Termo de Consentimento para Tratamento de Dados

Este termo é um modelo para uso futuro, caso o projeto utilize dados pessoais identificáveis.

## Consentimento  
O titular autoriza o uso dos dados exclusivamente para fins de pesquisa e desenvolvimento técnico.

## Garantias  
- Dados serão tratados com segurança  
- Não serão compartilhados com terceiros  
- O titular pode revogar o consentimento a qualquer momento

## Contato  
Dúvidas podem ser enviadas via GitHub ou e-mail institucional.
